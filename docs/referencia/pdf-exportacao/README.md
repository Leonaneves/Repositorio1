# Molde de exportação (Ficha_A4_PTBR_Impress_o.pdf)

Renders de referência do PDF fornecido para a etapa de exportação (ver `docs/04-builder-features-pdf-arquitetura.md`). Confirmado via `pdfinfo`: 2 páginas A4 (595,276 × 841,89 pt), **sem AcroForm, sem JavaScript** — export puramente gráfico do InDesign.

Visualmente idêntico ao PDF interativo da Fase 1 (`docs/referencia/ficha-pagina-{1,2}.png`) — mesma arte, mesmas caixas, tamanho de página praticamente igual (diferença <0,1pt). Por isso os 450 campos/retângulos já extraídos em `docs/referencia/campos-completos.json` servem como referência de coordenadas para este arquivo também.
